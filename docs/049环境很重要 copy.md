# 049环境很重要

纽约大学的社会学家就做了一次调查，企图给出实证数据。最近，他们公布了结果。社会学家按照收入，把所有美国的职业分成100个等级。收入最高的职业为100分，收入最低的职业为1分。在这个体系里面，医生是93分，空姐是53分，擦鞋工是9分。一共调查了2万多个人，结果发现，子女的等级与父母的等级，呈现明显的正相关。如果父母的职业在76分以上，子女的职业往往也是这个等级；如果父母的职业在25分以下，子女很可能也是如此。概率在50%以上。调查报告写道：

> "人们总说，美国是一块充满机会的大陆。事实并非如此，美国人的职业发展，最大的决定因素可能是父母。"
> 

注意，这是美国的调查结果，那个地方号称有"美国梦"，人们相信奋斗就能改变人生。如果在中国调查，我想正相关肯定更明显，父母因素的决定性将更大。一个表现就是，由于太缺乏改变人生的正常途径，才导致我们这里任何可能暴富的东西，都异乎寻常的流行，比如彩票、传销、互联网金融和加密货币。

环境是决定性的，但对于一个人来说，环境也是可以选的。一块大陆没办法选自己的形状，一个国家没办法搬起来，挪到一个更好的纬度。可是我们不是一块大陆，我们确实没办法选择自己生在哪个家、哪个国、哪个时代，按一部分环境是命运直接发给我们的牌。

但是等我们长大了，会发现一个件挺让人精神一振的事情，我们身边相当大一部分环境，忽然就变成了一道选择题，我们能选我们住在哪座城，我们能选我们进哪个行业，我们能选跟什么样的人待在一起，那个圈子就是我们每天呼吸的空气，我们还能选每天让什么样的信息流进自己的眼睛和耳朵，而在今天这个时代，这一条可能是所有环境中最厉害的那一种。

两个一样的人，一个每天晚上刷短视频、刷满屏的抱怨，另一个把同样的时间，泡在一群正在动手造东西，互相交换想法的人里，五年之后，这两个人就站在了两块不同的大陆上，而这两块大陆是他们一点一点选出来的。我们没法选择我们生在哪一块大陆上，但是成年之后，我们完全可以选自己要走到哪块大陆上去。

我们会慢慢不再盲目崇拜成功，再看见一个站在顶上的人，我们不会下意识就以为他天生比所有人聪明、比所有人高贵，我们会忍不住多问一句，是什么样的环境，什么样的时代，什么样的先发优势，把他一路托举到了这。我们不会再责怪每一个掉队的人，就只是因为不够努力。**很多我们叫做天赋的东西，其实是环境；很多我们叫能力的东西，其实是机会；很多我们叫努力的东西，其实是别人恰好就有的资源。**

这绝不是叫我们从此躺平，不再努力的借口，恰恰相反，这才是我们能够清晰地去努力的开始，当我们真的看清的时候，不再把一切都归到某种神秘的个人天赋上的那一刻，我们才终于能看清哪些能真正撬动命运的杠杆，其中最大的一根就是我们把自己放到什么样的环境。**人最大的外挂不是天赋，而是环境，有人习惯抱怨环境，有人懂得适应环境，而还有一种人懂得去选择环境，甚至亲手创造环境。**
