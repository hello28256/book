# 037有钱人和你想的不一样

### **有钱人和穷人不一样的十七种思考方式和行为**

1. 有钱人相信：“我创造我的人生。”穷人相信：“人生发生在我身上。”
2. 有钱人玩金钱游戏是为了赢。穷人玩金钱游戏是为了不要输。
3. 有钱人努力让自己有钱。穷人一直想着要变得有钱。
4. 有钱人想得很大。穷人想得很小。
5. 有钱人专注于机会。穷人专注于障碍。
6. 有钱人欣赏其他的有钱人和成功人士。 穷人讨厌有钱人和成功人士。
7. 有钱人与积极的成功人士交往。 穷人与消极的人或不成功的人交往。
8. 有钱人乐意宣传自己和自己的价值观。 穷人把推销和宣传看成不好的事。
9. 有钱人大于他们的问题。穷人小于他们的问题。
10. 有钱人是很棒的接受者。 穷人是差劲的接受者。
11. 有钱人选择根据结果拿酬劳。 穷人选择根据时间拿酬劳。
12. 有钱人想着：“如何两个都要？” 穷人想着：“如何二选一？”
13. 有钱人专注于自己的净值。 穷人专注于自己的工作收入。
14. 有钱人很会管理他们的钱。 穷人很会搞丢他们的钱。
15. 有钱人让钱帮他们辛苦工作。 穷人辛苦工作赚钱。
16. 有钱人就算恐惧也会采取行动。 穷人却会让恐惧挡住他们行动。
17. 有钱人持续学习成长。 穷人认为他们已经知道一切。

### **致富法则**

1. 你的收入，只能增加到你最愿意做到的程度！
2. 如果你想改变果实，你首先必须改变它的根；如果你想改变看得见的东西，你必须先改变看不见的东西。
3. 金钱是一种结果；财富是一种结果；健康是一种结果；生病是一种结果；你的体重也是一种结果。我们活在一个有因有果的世界。
4. 想法产生感觉，感觉产生行动，行动产生结果。
5. 假如我们的潜意识必须在深植的情感和冷硬的逻辑之间做出抉择，情感几乎是每战必胜的。
6. 如果你的动力来源并不是正面的，例如你是出于恐惧、愤怒而想致富，或者只是为了“证明”自己而想成功，那么你的钱永远不会带给你快乐。
7. 如果想彻底改变室内温度，唯一的办法是重新设定温度调节器。同理，想“彻底”改变你的理财成绩，唯一的办法是重新设定你的财务温度调节器，也就是你的财富蓝图。
8. 保持自觉，就是可以时时观看自己的想法和行动，好让你能够做出自己真心想要的抉择，而不是被过去的设定所操控。
9. 你可以选择那些会鼓励你获得幸福和成就的思考方式，而舍弃那些不能支持你获得幸福的思考方式。
10. 钱，在它能发挥效用的地方实在是太重要了；而在它不能发挥作用的地方，它就完全不重要了。
11. 你在抱怨的时候，其实是在吸引更多“烂事”进入你的生活中。
12. 天下没有所谓的“有钱的受害者”这回事！
13. 如果你的目标是过得舒服就好，你就很可能永远也不会有钱。但是如果你的目标是赚大钱，那么你最后很有可能会舒服得不得了。
14. 大部分人没办法得到他们想要的东西，最大的原因是他们不知道自己想要什么。
15. 如果你不是全心全意、真心真意想创造财富，那么你很可能创造不出多少财富。
16. 你的收入，与市场认为的你所产出的价值成正比。
17. 祝福你想要的事物。
18. 领导者赚的钱远远多于跟随者！
19. 成功的秘诀，就是不要逃避问题，不要在问题面前退缩；成功的秘诀就在于你要成长，让自己大于一切的问题。
20. 如果你的生活中有一个大问题，这只说明了一件事：你很小！
21. 如果你说你有价值，你就有价值；如果你说你没有价值，那么你就没有。然后你就会依照你的故事版本而活。
22. 如果一株百尺高的橡树拥有和人类一样的心灵，那么它顶多只能长到十尺。
23. 只要出现一个给予者，就有一个接受者；而每一个接受者的对面都是一个给予者。
24. 金钱只会让你现有的自己更加扩大。
25. 你做一件事情的方式，就是你做所有事情的方式。
26. 拥有稳定的薪水没什么不对，除非它阻碍了你用自己的能力赚取你所值得的金钱—问题是，“稳定的薪水”这概念往往就会阻碍你赚更多钱。
27. 永远不要为你的收入设定上限。
28. 真正衡量财富的标准是净值，不是工作收入。
29. 注意力所在的地方，就会有能量流动，也就会出现结果。
30. 除非你能管理你现有的一切，否则你不会再得到更多！
31. 你管理金钱的习惯，比你拥有的钱财数目更重要。
32. 不是你控制钱，就是钱控制你。
33. 有钱人把每一美元都视为“种子”，把它种下之后可以多赚一百美元，再把这些赚到的钱种下，又多回收一千美元。
34. 行动是内在世界和外在世界之间的“桥梁”。
35. 真正的战士可以驯服这条叫作“恐惧”的眼镜蛇。
36. 不必把恐惧除掉也能成功。
37. 如果你只愿意做轻松的事，人生就会困难重重。但如果你愿意做困难的事，那么人生就会变得轻松。
38. 你只在一种状况下是真正在成长的，那就是你觉得不舒服的时候。
39. 就追求成功和快乐来说，你最应该学习的技巧，就是训练并管理你自己的心。
40. 你可以是对的，你也可以是有钱的，但你不会两者都是。
41. 每一位大师都曾经有过失败。
42. 想得到最高的薪水，你必须是最好的。
43. 真正的富有，取决于一个人能够付出多少。
