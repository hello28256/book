# 001Tips

1. 人生就像玻璃窗上的苍蝇，前途一片光明，却找不到出路。
2. 读再多的书都不如内生动力给人带来的变化大。
3. 如果你在很年轻的时候，就遭受到了失败，一定要把它当作老天送你的礼物。如果等到四十岁再失败，你会经受不起的。为什么年纪越大，走路越小心，因为越来越经不起跌倒了。
4. 人必有痴，而后有成
5. 人一生最大的幸运，就是在年富力强时发现了自己的人生使命。
6. "你们的时间有限，所以不要把它浪费在过其他人的生活。最重要的是，你要有勇气跟随你的内心和直觉。某种程度上，它们已经知道你真正想要成为什么样子。其他所有事情都是次要的。”
7. 金钱最有价值的用途就是购买时间。
8. 大多数人都高估了他们一天能做的事情，但低估了他们一年能做的事情。
9. 我们这个时代的痛苦在于，那些愚蠢的人都非常自信，那些有想象力和理解能力的人充满了怀疑和犹豫不决。
10. 多年使用 Vim 之后，我有一个顿悟：如果坚持使用默认配置，就可以在任何环境中毫无困难地使用 Vim。
11. 人生所有的事情之中，后悔是最可怕的。失败是一种答案，拒绝也是一种答案，但后悔却是永远得不到答案。“要是我当初……”、“如果我那样选了……”、“不知道如果走了那条路会怎样……”，你永远、永远都不会知道答案，而且这些疑问会纠缠你一辈子。
12. 问名字还是问机制。
13. 经师易求，人师难得
14. "普通人性中最令人遗憾的一种人性就是嫉妒，因为嫉妒的人不会从自己拥有的东西中寻找快乐，而会从其他人拥有的东西中找寻痛苦"。嫉妒是不同阶级，国家，性别之间趋于公平的主要动力。同时，期望通过嫉妒来获得那种公平也会是最糟糕的公平。它在削减幸运者的快乐，而不是增加不幸者的快乐。
15. 钱是工具，不是目的。
16. **人是微不足道的尘埃，也是能够理解宇宙的尘埃。**
17. **不要问生命有什么意义，而要创造生命的意义。**
18. **我们无法让时间停留，但可以让时间经过我们时，留下温度。**
19. 不是不起念，而是不随念转。
20. **也只有在做自己事业的时候，你才能不惧困难，勇敢地面对一切。那种想找一个安稳的避风港的心态不会让你平静，你要知道世界本来就是不平静的，找到自己的归宿和目标才可能让你真正平静。**
21. **人生最大的意义，不一定是获得什么，而是在不断成长、创造、爱与被爱中，让自己的生命变得更加丰富而充实。**
22. **智慧的人讨论思想，聪明的人讨论事情，愚蠢的人讨论别人。**
23. **生活的真相，就是生活并不总是如你所愿。**
24. **改过者：要有羞愧心，要有敬畏心，要有勇于改过心。**
25. **想少走弯路的人，容易陷入“寻找捷径”；而追求本质的人，反而自然减少了弯路。**
26. 我越来越感觉书其实是一个高度浓缩的一个结果，写书的人花了十几年或者一生才能写出一本，这是他思考留下来的一个成果，而很多人却想在短短的几个小时或者几天，就能完全理解或者说掌握，然后内化，这很难。我们每个人的背景和人生经历都不一样，需要去种树，而不是老是想着吃别人的果实，要自己去结果，读书更多的是引发思考，而不是直接吸收。要读经典，因为经典是经历过时间考验，也不要着要完全理解甚至做到，知道到做到之间有理解、实践、体验、内化，这是世界上最遥远的距离。读书是借别人的树荫，最后还是要自己种一棵树。经典给你种子，人生给你土壤，时间负责生长，而真正属于你的果实，只能由你自己结出来。
27. 很多公司在招聘软件上放的招聘信息，其实一定程度上是假的，很多公司其实根本不招人，又要显示出团队在扩张，实际情况是下个月工资都快发不出了。
