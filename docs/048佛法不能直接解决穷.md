# 048佛法不能直接解决穷

### 佛法不能代替劳动

如果一个人不工作、不种田、不学习技能，只是天天念经，希望明天银行卡里多一百万。佛法不会这样运作。饿了还是要吃饭，病了还是要看医生，没钱还是要赚钱。所以佛教有句话：自依止，法依止。意思就是要靠自己的行动，而不是等待奇迹。

- **经济学、教育、技术、工作** ：解决温饱、财富和生产问题。
- **佛法** ：解决贪、嗔、痴，解决内心如何面对得失、生老病死和无常的问题。

一个人既可以认真工作、创业、赚钱，也可以学习佛法，培养内心的智慧与慈悲。这两者并不矛盾。可以用一句话来概括：**温饱是生活的基础，佛法是心灵的方向。前者回答「怎么活下去」，后者回答「活着是为了什么，以及怎样活得少一些痛苦」。**

**举个例子假设有两个人。第一个人今天没有饭吃，他真正需要的是：工作机会、食物、社会保障、医疗。这时候如果只跟他说："一切都是空"，这是没有帮助的。第二个人年收入五百万，每天担心股票跌、公司倒闭、别人超过自己、睡不着觉。他的问题已经不是"吃不上饭"。而是即使拥有很多，也无法安心。这时候佛法讨论的内容，就非常贴近他的问题。**

佛陀并没有要求所有人都出家。对于在家居士，他一直强调：通过正当职业赚钱（正命），不欺骗、不偷盗，合理储蓄和使用财富，承担家庭责任。所以一个在家学佛的人，完全可以努力工作、创业、追求经济独立。佛法并不是要人放弃现实，而是提醒财富很重要，但财富不能代替内心的安稳；没有财富会有一种苦，有了财富也未必没有苦。

我觉得可以用一句话概括佛法和现实生活的关系：佛法不是教人不要赚钱，而是教人在赚钱、拥有财富、失去财富时，都尽量不被贪、嗔、痴牵着走。

### 佛陀是怎么解决"穷"的？

对个人，学一门技能、勤奋工作、正当赚钱、合理储蓄、不赌博、不酗酒、不挥霍、培养诚实和信用。虽然佛法不能直接给你钱，但它会影响赚钱的能力。

- **减少贪心，不容易被骗；**
- **减少瞋恨，与同事、客户关系更好；**
- **减少懒惰，更容易坚持学习；**
- **少一些焦虑，做决定更冷静；**
- **少一些欲望，不乱消费。**

这些都不会直接变成财富，却可能间接改善一个人的经济状况。所以有人说：佛法不能给你鱼，但可以让你成为一个更会捕鱼的人。

### 那贫穷是不是也是一支毒箭？

**如果一个人已经吃不上饭了，那么可以说，贫穷就是他眼前的一支毒箭。今天没有饭吃、孩子生病没钱治、没有地方住。这时候最需要的是找食物、找工作、求助社会、获得医疗。如果有人这时候只说："你不要执著"，这并不能解决他的燃眉之急。从慈悲的角度来说，先帮助他脱离困境，更符合佛教精神。**
