# 045乱滴的喇叭

今天和我哥出去散步，在深圳街头遇到很多拉客的摩的。有些摩的改装了很大的喇叭，声音甚至比汽车喇叭还要刺耳，几个人一路不停地按喇叭，让我觉得很不舒服，于是忍不住说了一句：“这些人一点素质都没有”，但我哥却和我说：“别人做什么和你有什么关系吗？你就评价别人，你还是太容易被外界影响了，这种现象在哪里都会存在，你无法改变所有人，能做的只是管理好自己”，在这个信息爆炸的时代，我们每天都会接触大量的负面消息。如果我们把注意力都放在外界的混乱、不完美和别人的行为上，自己就很累。

**看到摩的，声音只是声音，发生就是发生，没有额外加上“这个人没素质”、“社会怎么这样”、“为什么影响我”，没有一个“我”站出来和这个事情对抗。所以不是我努力保持平静。而是本来就没有什么东西需要被扰乱。**

这和斯多葛哲学（Stoicism）有一个很像的观点，**不要把精力浪费在无法控制的事情上。**

你不能控制路上的噪音、别人的素质、别人的选择、世界的不完美，但你可以控制自己的反应、自己是否愤怒、自己今天要做什么。

比如看到有人乱扔垃圾第一种反应，“这些人太没素质了，社会怎么这样，我一天心情都不好”，第二种反应，“确实不文明，我自己不这样，也提醒身边人，继续过自己的生活”，后者更有力量。

**谁能在海量信息中保持自己的方向。就像一艘船，海浪一定会有，风一定会吹，别人的船也一定会经过。但优秀的船长不是让海面永远平静，而是在波浪中保持航向。**

**世界不会因为你的烦恼而改变，但你的注意力决定了你会成为什么样的人。**
