# 052茅坑淘金

“人在疲惫的时候，会滋生出冷漠和暴躁；人在贫穷拮据的时候，会变得狭隘和自私；人只有在快乐的时候，才会产生包容和乐观。很多时候，所谓的性格，其实不是一个人固定的品质，而是他所处状态的外显。” 

这是我在抖音看到采访麦家，麦家说的，连口型都一致。然后我在抖音搜索了一下，可以找到无数条同样的视频，但是我感觉语气一直很平，不像一个正常人说话，然后我就去B站看完整的采访视频，但是并没有找到那句话。甚至对于一个理工科毕业两年的本科生，第一反应都是这句话确实很有道理，等过了很久才回想这句话，发现这句话很傻逼，更别说那些已经无法自己思考的人了，他们每天都喝这些毒鸡汤，把这些傻逼的“金句”当成信条，那不完蛋了？思考不对不如不思考，看垃圾不如不看。佛陀举过一个蛇喻，有人抓毒蛇抓尾巴，一定被咬。抓正确位置才能控制蛇。佛陀说：佛法也是，理解错误，反而害自己。

这段话本身虽然听起来很有道理，但它的语言结构非常像今天短视频平台流行的“金句”：疲惫 → 冷漠和暴躁、贫穷 → 狭隘和自私、快乐 → 包容和乐观、性格 → 状态的外显。这种高度工整的排比，非常适合短视频传播。它不像自然访谈中一个人临场说出来的话，更像是经过文字加工后的成品。现在短视频时代，很多人已经形成了一个非常奇怪的传播链：一个账号编一句话 → 配名人视频 → 第二个账号搬运 → 第三个账号说“某某曾说” → 第四个账号继续引用 → 最后大家看到几百条内容，就以为这是名人的名言。事实上，真实的情况可能比这句话复杂得多，人的性格既有相对稳定的部分，也会受到疲劳、贫困、压力、安全感、社会环境的影响。状态会改变一个人的表现，但不能完全解释一个人的性格。细想这句话确实有明显的问题。它的问题不是完全没有道理，而是把一个有条件成立的心理现象，说成了一个普遍的人性规律。

“人在疲惫的时候，会滋生出冷漠和暴躁。” 这句话有一定道理。疲劳会降低人的情绪调节能力，更容易烦躁、失去耐心。但问题是疲惫的人不一定冷漠和暴躁。**有些人疲惫的时候反而更安静、更柔软，甚至因为自己知道辛苦，所以更能体谅别人。所以更准确的说法应该是疲惫可能让一个人更难控制情绪，但不决定一个人会如何对待别人。**

“人在贫穷拮据的时候，会变得狭隘和自私。” 这个问题更大。贫穷确实可能造成资源稀缺感，让人更关注眼前的生存问题，从而减少对他人的帮助。但贫穷并不等于自私。**历史上有很多贫穷的人非常善良，也有很多富裕的人非常冷漠。甚至有时候恰恰相反，一个人经历过贫穷，可能更懂得帮助别人。所以这里把“经济状态”和“道德品质”直接绑定，是一种过度简化。**

“人只有在快乐的时候，才会产生包容和乐观。” 这一句我觉得是整段话里最有问题的。因为如果按照这个逻辑，痛苦的人就不会包容，贫穷的人就不会善良，疲惫的人就不会温柔。那现实中的很多伟大人物都无法解释了。**很多人的善良，恰恰是在痛苦中形成的。很多人的包容，恰恰来自自己曾经受过伤害。很多人的乐观，也不是因为生活一直快乐，而是因为经历过痛苦以后，依然选择乐观。所以快乐可以让人更容易包容，但包容并不需要快乐作为前提。**

“所谓的性格，其实不是一个人固定的品质，而是他所处状态的外显。” 这句话我觉得是一个非常漂亮，但过于绝对的命题。人的性格当然会受到状态影响，但性格不等于状态。比如同样是疲惫。一个人会暴躁，一个人会沉默，一个人会说：“不好意思，我今天有点累，可能没办法好好聊天。” 三个人的状态完全相同，但表现却不同。这说明状态影响行为，但性格决定一个人在状态影响下，倾向于如何行动。甚至可以说，真正能看见一个人性格的，恰恰不是他快乐的时候，而是他在疲惫、贫穷、失意、愤怒的时候，依然选择怎么对待别人。当然，这也不是说“人在极端状态下必须保持完美”。一个人疲惫时偶尔暴躁、贫穷时产生焦虑，这都很正常。我们不能要求人在任何情况下都保持圣人般的理性。但如果一个人长期如此，那么“状态”可能只是诱因，而不是全部原因。

如果要改得更严谨，可以变成：**人的状态会影响他的行为，但不会完全决定他的品格。疲惫可能让人暴躁，贫困可能带来焦虑，快乐也可能让人更宽容。但一个人的真正性格，往往体现在他受到这些状态影响之后，依然如何选择。**

这里面有一个更深的问题：**如果一个人的善良只有在顺境中才能存在，那它究竟是善良，还是仅仅因为他有余力？**
