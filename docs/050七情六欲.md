# 050七情六欲

七情最常见的一种说法是：**喜、怒、哀、惧、爱、恶、欲**

分别是：

- **喜：开心、快乐**
- **怒：愤怒、生气**
- **哀：悲伤、难过**
- **惧：害怕、恐惧**
- **爱：喜爱、眷恋**
- **恶：厌恶、憎恨**
- **欲：想要、渴望**

“六欲”常见的解释来自佛教，指人的六种感官欲望，对应六根：**眼、耳、鼻、舌、身、意**

因此产生：

- **眼欲：想看美好的东西**
- **耳欲：想听悦耳的声音**
- **鼻欲：喜欢香味**
- **舌欲：追求美食、美味**
- **身欲：追求身体上的舒适、触感**
- **意欲：思想、意识上的欲望和追求**

**一个人真正的修养，并不是让自己变成一个没有七情六欲的人，而是有情绪，但不被情绪完全控制；有欲望，但知道如何与欲望相处。**
